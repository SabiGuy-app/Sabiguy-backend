# Contributing

## How to contribute

1. Create or update your feature branch from the latest `dev` branch.
2. Make your changes with clear, focused commits.
3. Run the relevant tests and verify your changes locally.
4. Push your branch to the remote repository.
5. Open a pull request that compares your branch to the `dev` branch.
6. Request a review from the appropriate reviewer before merging.

## Development setup

- Install dependencies:
  ```bash
  npm install
  ```
- Start the development server:
  ```bash
  npm start
  ```

## Coding guidelines

- Follow the existing code style and structure.
- Keep changes small and easy to review.
- Add or update documentation when behavior changes.
- Write meaningful commit messages.

## Pull request checklist

- [ ] Code runs locally
- [ ] Relevant tests were added or updated
- [ ] Documentation was updated if needed
- [ ] PR description clearly explains the change

Thank you for contributing!
